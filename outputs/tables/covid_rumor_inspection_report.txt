3 LABELS / LANGUAGE
Observed labels are reported above without conversion. Authors define T=True factual, F=False/made-up or false information, U=Unverified/hard to judge at labeling time.
Veracity is item-level. Fact-check labels from Snopes/PolitiFact/Boomlive are used directly; multiple sources use majority voting. Social items are checked against authoritative sites, common sense, and otherwise assigned U. Authors report manual cross-validation.

  EN_DUP conservative English-looking heuristic: 7177/7179 (99.97%).
The heuristic requires >=90% Latin letters; it is a script check, not language identification. Non-English/mixed snippets can exist. en_dup is unprocessed combined English-designated data, not a filtering key.

7 ENGAGEMENT / PROPAGATION
NEWS popularity: derivable as per-item website-record count; unique reposting websites also derivable. Dates/stance are incomplete where fields are missing. It is website repost/discussion visibility, not a Twitter post count.
TWITTER direct aggregate coverage: reply=99.96%, retweet=99.96%, like=99.96%; total engagement is derivable as their sum. Response count/timing/stance derive only for the 1,383 items with files.
Data-quality caution: retweet count equals like count exactly in 689/2,705 main rows; preserve both raw fields but validate this pattern before modeling.
The source/file key is described by the paper as a fakeID and is not safe to interpret as a native Twitter Snowflake ID; no timestamp was decoded from it.
No true cascade topology is present. TWITTER has aggregate counts and first-order response records without child tweet IDs/users/types; NEWS has item->website sets without repost-to-repost edges. No recursive reply graph, retweet edge graph, user-user network, or cascade can be reconstructed.

9 SUITABILITY / RECOMMENDATION
Subset choice: Option B—use both only for different questions, never combined. NEWS is closer to FakeHealth's content-level unit but contains short statements and website reposts, not articles plus Twitter mappings. TWITTER has richer direct counts but a post-level unit and no propagation edges.
Dataset role: B—supplement CoAID as an independent COVID robustness dataset, not replace it. It adds T/F/U labels, website repost popularity, retweets, likes, response text/time, stance and sentiment. It worsens unit alignment with FakeHealth and does not provide content->many-tweet diffusion mappings or graph topology.
Primary common features if used: dataset, subset, content_id, veracity_original, short_text, sentiment, engagement_present; NEWS-only website_record_count/unique_website_count; TWITTER-only reply_count/retweet_count/like_count/total_engagement. Cross-context primary models should not equate NEWS website reposts with FakeHealth tweets, and temporal variables should remain subset-specific/sensitivity measures.
Overall: not better than CoAID for the main FakeHealth comparison. CoAID remains primary because its unit is content and its mapped tweet/reply measurements align more directly with FakeHealth. COVID Rumor is valuable robustness evidence for different engagement constructs.
